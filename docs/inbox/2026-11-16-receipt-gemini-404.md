# СРОЧНО: «Чек по фото» — ошибка 404, неверное имя модели Gemini

**От:** Hermes, 2026-11-16. Скриншот у Андрея: `Gemini ответил ошибкой 404: models/gemini-3.8 is not found for API version v1beta`.

## Причина
`index.html:3769` — `GEM_MODEL='gemini-3.8'`. Такой модели нет: у Google имена всегда с вариантом, например `gemini-3.8-flash`. В 4.13 модель меняли, видимо отрезали суффикс `-flash`.
Актуальный список: https://ai.google.dev/gemini-api/docs/models (на 2026-11-16 есть `gemini-3.8-flash`, `gemini-3.6-flash`, `gemini-3.5-flash-lite`, алиас `gemini-flash-latest`; Gemini 4: `gemini-4-hydrogen/argon/carbon`).

## Что сделать
1. Заменить модель на `gemini-flash-latest` (алиас Google, сам переключается на новую Flash, о смене предупреждают за 2 недели). Если важна стабильность: `gemini-3.8-flash`. Проверить, что выбранная модель доступна на **бесплатном** ключе AI Studio.
2. Защита от повторения (уже второй раз ломается из-за модели): при 404 от `generateContent` вызвать `GET /v1beta/models` с ключом, выбрать первую модель с `flash` в имени и `generateContent` в `supportedGenerationMethods`, сохранить в localStorage и повторить запрос. Проверку ключа (строка ~3799) тоже перевести на этот выбор.
3. **Проверить по-настоящему** с ключом владельца или своим тестовым: живой запрос к API с реальным фото чека, ответ разобран, позиции разложены по категориям и подкатегориям, показан экран согласования. Не выпускать без живого запроса.

## Готово, когда
Андрей на телефоне фотографирует чек → видит позиции по категориям/подкатегориям → правит/подтверждает → записи внесены. Выпуск — после его «да». Фикс только веб-части (index.html), APK не нужен.
