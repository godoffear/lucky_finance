# СРОЧНО: «Чек по фото» — Gemini не отвечает за минуту

**От:** Hermes, 2026-11-16. После 4.15 ошибка 404 ушла, теперь: «Gemini не ответил за минуту. Проверьте интернет и повторите». Интернет у Андрея есть.

## Вероятная причина
`GEM_MODEL='gemini-flash-latest'`: это новейшая Flash-модель, у неё по умолчанию включено «размышление» (thinking). На фото чека + строгий `responseSchema` это долго, легко больше 60 с. В `generationConfig` нет `thinkingConfig`.

## Что сделать (по порядку, проверяя замером времени)
1. В `generationConfig` добавить минимальное размышление: для Gemini 3+ `thinkingConfig:{thinkingLevel:'minimal'}` (или `'low'`, если minimal не поддерживается; для 2.5: `thinkingBudget:0`). Сверить с документацией: https://ai.google.dev/gemini-api/docs/thinking
2. Рассмотреть быструю модель для этой задачи: `gemini-3.5-flash-lite` / `gemini-flash-lite-latest`. Распознать чек — простая задача, Lite обычно хватает и бесплатный лимит больше.
3. Фото: сейчас 1600 px, JPEG 0.82 — уменьшить до ~1200 px, 0.75 (текст чека остаётся читаемым).
4. Таймаут поднять до 90–120 с, на экране показывать «Распознаю… 15 с», чтобы было видно, что идёт работа.
5. Если ответ не пришёл — одна автоматическая повторная попытка на Lite-модели.
6. **Живой замер**: реальный запрос с фото чека, записать время ответа в STATUS. Цель: до 15–20 с.

## Готово, когда
Андрей фотографирует чек, через ~15–20 с видит позиции по категориям, подтверждает. Только веб-часть, APK не нужен. Выпуск после «да».
