# СРОЧНО: «Чек по фото» — перейти на Flash-Lite (замер Hermes на реальных чеках)

**От:** Hermes, 2026-11-18. Андрей ждал 2+ минуты без результата (4.17/4.18).

## Замер (сервер Hermes, бесплатный ключ AI Studio, тот же промпт/схема/1200px/q75, 4 реальных чека Андрея)
| Модель | Время | Результат |
|---|---|---|
| `gemini-flash-latest` + `thinkingLevel:'minimal'` | 0.2 с | **400: Thinking level MINIMAL is not supported for this model** |
| `gemini-flash-latest` без thinkingConfig / `low` | **>120 с, таймаут** | — |
| `gemini-flash-lite-latest` (= `gemini-3.5-flash-lite`) + minimal | **2.2–3.5 с** | все 4 чека, total совпал |
| `gemini-3.5-flash-lite` + minimal | **1.6–3.1 с** | все 4 чека, total совпал |
| `gemini-2.5-flash-lite` | — | 404, недоступна новым пользователям |

## Причина зависания
Основная модель `gemini-flash-latest` отвечает 400 на `minimal` → `gemPost()` видит /thinking/ и удаляет `thinkingConfig` → модель думает в полную силу → >90 с → abort.

## Что сделать
1. Основная модель для чеков: `gemini-flash-lite-latest` с `thinkingLevel:'minimal'`. Запасная: `gemini-3.5-flash-lite`. `gemini-flash-latest` для чеков не использовать.
2. Если 400 про thinking — не удалять thinkingConfig, а ставить `'low'`.
3. Таймаут 30 с (норма 2–4 с), текст «Обычно 3–5 секунд».
4. `gemFind()` (авто-выбор при 404): предпочитать модели с `lite`, а не исключать их.
5. **НДС:** на чеке KRESTOK сумма позиций 38 889 (без НДС 8%), итог 42 000. Если сумма позиций ≠ total, распределять разницу пропорционально по позициям (или отдельной строкой «НДС» в категорию самой крупной позиции), чтобы записалось ровно total.
6. Дата: на чеке «08/11/2026» модель вернула 2026-11-09. В промпт: «вьетнамские даты в формате ДД/ММ/ГГГГ». Показывать дату на экране проверки крупно.
7. Мелочь: «KEO SIEU DINH» распознан как «Скотч», это суперклей. Не критично, пользователь правит при проверке.
8. Живой замер на телефоне после правки, время записать в STATUS.

Только веб-часть, APK не нужен. Выпуск после «да» Андрея.
