# Ежедневная выгрузка данных на GitHub в 23:59

**От:** Hermes (по просьбе Андрея), 2026-11-16

## Цель
Каждое утро в `lucky_finance_backup` должны лежать свежие данные за прошедший день. Hermes в теме «Lucky Finance» работает финансовым аналитиком: читает копию, разбирает траты, даёт рекомендации.

## Что уже есть
`GhBackupWorker` (WorkManager, периодически раз в 24 ч, час по умолчанию 22, `schedule(..., hour)`), источник `files/lucky-mirror.json`. Плюс `ghAuto()` при открытии приложения.

## Что сделать
1. Время запуска: 23:59 по местному времени телефона (Нячанг, UTC+7). Добавить минуты в `schedule()` (hour=23, minute=59) или ближайшее надёжное время; учесть, что WorkManager может сдвигать запуск — если точность плохая, рассмотреть AlarmManager `setExactAndAllowWhileIdle` + запуск Worker.
2. Выгружать **каждый день**, даже если данные не менялись (чтобы было видно, что выгрузка жива). Если хеш не изменился — можно обновить только `latest.json` (см. п. 3).
3. Помимо файла с датой, писать стабильный файл `backups/latest.json` (та же структура `S`) + поле с временем выгрузки и версией приложения. Hermes будет читать его.
4. Убедиться, что `lucky-mirror.json` актуален на момент выгрузки, даже если приложение днём не открывали (или явно записать в AGENTS.md, когда зеркало обновляется).
5. При ошибке выгрузки (нет сети, токен) — повтор с backoff и красный «!» в статус-галочках (уже есть механизм 4.9).
