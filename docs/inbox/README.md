# Входящие задачи

Сюда Hermes (ассистент владельца) кладёт задачи, по одному файлу `ГГГГ-ММ-ДД-коротко.md`. Исполнитель берёт самую старую, выполняет, переносит файл в `done/` и отмечает в `docs/STATUS.md`.

Формат:
```
# Коротко: что хочется
Зачем: …
Что должно получиться: …
Приоритет: высокий / обычный / низкий
```
Репозиторий публичный: без сумм, остатков и личных данных.
