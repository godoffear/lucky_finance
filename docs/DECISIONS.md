# Решения владельца, отложенное и «не делать»

Сверяйся с этим файлом, прежде чем предлагать идеи. Обновляй его, когда появляется новое решение.

## Принято и сделано
- **Курсы:** убрали «свой / официальный курс». Порядок: FIFO-средний по лежащим партиям → ручной → рыночный → ЦБ.
- **Прогнозы** показываются только после 30 дней данных. Счета можно отключать от прогноза (например, карту РФ).
- **Категория «Еда» → «Продукты»** (еда вне дома остаётся отдельной).
- **Лимиты:** кольца убрали; в «Отчёте» и «Лимитах» — полосы и кольцевая диаграмма.
- **Накопления:** калькулятор «Как дойти до цели»; копилка в нескольких валютах, видны рублёвый эквивалент и рыночная стоимость.
- **Мопед** (2.22): подкатегории Топливо / Обслуживание / Покупка. «Покупка» — разовая, не входит в среднюю трату в день.
- **Мама** (2.27): категория для переводов маме; в среднюю трату в день и прогноз не входит.
- **Цитата дня** на главной (2.24), можно выключить.
- **Иконка** (2.23): четырёхлистный клевер в золотой подкове.
- **Имя файла копии** (2.25): `LuckyFinance_backup_ГГГГ-ММ-ДД_ЧЧ-ММ.json`.
- **Цветные темы** (2.26): Изумруд, Закат, Океан, Неон, Лаванда рядом с «Классикой».
- **Копия на GitHub** (2.28): в приватный репозиторий пользователя, токен в отдельном ключе `fin-mvp-gh`, автовыгрузка раз в день при открытии, если данные менялись.
- **Финпомощник:** приложение само AI не вызывает; сводка выгружается и задаётся вопрос на отдельной странице-артефакте claude.ai за счёт подписки пользователя.
- **Подкатегории** (2.29, 2.30): необязательные, на механизме `SUBS`. Продукты (фрукты и овощи, мясо/рыба/яйца, молочка/хлеб/бакалея, кулинария, прочее), Еда вне дома (кафе, стритфуд, доставка), Кофе и напитки (кофе, напитки), Здоровье (аптека, врачи, страховка), Жильё (коммуналка, прачечная), Спорт (тренажёрный зал, спортивное питание). Алкоголь и бары пользователь убрал. Свои подкатегории по-прежнему отложены.
- **Отчёт** (2.31): прогноз до 30 дней данных — компактная плашка; «Пульс месяца» выше, разовые траты золотой меткой; в категориях топ-5 и «Ещё N категорий»; подкатегории полосками; графики по месяцам только с месяцев с данными.
- **«Разовая трата»** (2.32): переключатель в форме расхода (поле `oneoff`, хранится только если отличается от умолчания). Все расходы остаются в итогах, категориях и остатках; разовые не входят только в среднюю трату в день и прогнозы. По умолчанию разовые: «Мопед · Покупка» и «Мама». «Среднее в день» в «Итогах месяца» считается без разовых.
- **Главный экран:** без отдельных «колец лимитов» и без уведомления «отложи после зарплаты» — пользователь отверг. Под выбором валют подсказки спрятаны под спойлер.

- **Версия 3.0 — формат APK (Capacitor)**: убраны установка на «Домой», iOS-код, service worker, баннер обновления; шрифты лежат в `fonts/` (кириллица, латиница, вьетнамский). Кнопка «Назад», вибро, чёрная AMOLED-тема, уведомления о платежах и лимитах, виджет, ярлыки (`luckyfinance://op/<тип>`), автокопия файлом в «Документы/LuckyFinance», страховочная копия данных внутри приложения, экспорт месяца CSV и PDF. «Что нового» — последние 5 версий.
- **Темы (3.0):** остались «Классика», «Эспрессо» (кофейная, тёмная) и «AMOLED»; Изумруд, Закат, Океан, Неон, Лаванда убраны.
- **Обновление из GitHub (3.1):** кнопка в «Ещё», приложение скачивает файлы из GitHub Pages в память телефона и переключается на них без переустановки APK; проверено на эмуляторе (успешное обновление и откат сломанной версии). Новый APK нужен только при смене нативной части.
- **Виджеты (3.2):** три размера (маленький 2×2, полоска 4×1, подробный 4×2); валюта сумм и «скрывать суммы» выбираются в «Ещё → Виджет на рабочем столе».
- **Копия на GitHub (3.2):** в приложении уходит каждый вечер в фоне (WorkManager, час 19–23, по умолчанию 22:10) из внутренней копии данных `lucky-mirror.json`; при открытии после этого часа выгружается сразу; запасной вариант — если копии не было больше 30 часов.
- **Новый APK внутри приложения (3.3):** файл лежит в `apk/LuckyFinance.apk` на GitHub Pages; приложение скачивает его, проверяет контрольную сумму и открывает установку Android без браузера. Для публикации в Google Play такой способ не подходит (там обновляет только Play), тогда нужна отдельная сборка без этой функции.
- **Обмен и перевод (3.4):** в форме можно выбрать любой другой счёт; тип выбирается по валютам (одна валюта → перевод, разные → обмен, тогда нужна сумма «Получаю»).
- **Сладости (3.5):** подкатегория «Сладости и снеки» 🍫 у «Продуктов» (отдельную категорию пользователь не выбрал).
- **Спорт и развлечения (3.6):** «Спорт → Пиклбол» 🏓; у «Развлечений» подкатегории: Кафе и рестораны, Кино и концерты, Экскурсии и парки, Игры и клубы (повседневная еда вне дома остаётся в «Еде вне дома»).
- **Еда вне дома (3.7):** остались «Стритфуд» и «Доставка» (еда с собой); «Кафе и рестораны» только в «Развлечениях» (когда сидишь в заведении — общий счёт). Старые записи перенесены один раз (`migCafe`, до `sanitize`).
- **Пиклбол (3.8):** пять операций октября (19, 21, 23, 25, 28 числа) перенесены в «Спорт · Пиклбол» разовой правкой `migPickle` в `normalize()` по id из копии. Правку можно удалить из кода после того, как владелец обновился.
- **«Операции» (3.9):** фильтры в окне (тип, период, счёт, несколько категорий и подкатегорий), итог найденного сверху, режим «По категориям». План дальше: главная (убрать шум, баннер копии, цитату, объединить «Обмен»/«Перевод»), «Ещё» (группы, пояснения за «?»), «Отчёт»; решения по редким разделам ждут ответа владельца.
- **Версия 4.0 (упрощение):** главная — три числа (всего, сегодня, на сколько хватит), 3 кнопки, топ-3 категории; «Обмен» и «Перевод» — одна форма «Перевод» (тип по валютам, плашка «Откуда → Куда»); из меню убраны (данные хранятся): долги, инвестиции, шаблоны, сверка, финпомощник, постоянные платежи, лимиты, уведомления, напоминания о копии, цитата дня. Владелец этим не пользуется.
- **«Отчёт» (4.1):** «Расходы по категориям» вверху с галочками, донат, итоги и «Пульс» считаются по выбранному, выбор отдельный от «Операций»; «На сколько хватит» и «Прогноз на конец месяца» в спойлерах.
- **Сверка с банком (4.2):** разовая правка `migNov` (пиклбол 01.11 = 100 000, пиклбол 03.11, парковка мопеда 210 000 в «Мопед → Обслуживание»); подписка Claude остаётся с датой 30.10 (владелец не захотел переносить); подкатегорию «Парковка» не добавлять.
- **Недельный отчёт (4.3):** переключатель «Месяц / Неделя» в «Отчёте», неделя пн–вс, тепловая карта в спойлере, выключатель в «Ещё». Тёмная тема: оставляем «AMOLED» как есть, новые не добавлять.
- **Упрощение и сортировка категорий по частоте (4.4):** в форме расхода 8 быстрых категорий по частоте, «Сигареты» 🚬 в штатном списке, убраны 5 нулевых категорий (Путешествия, Подарки, Питомцы, Дети, Дом и ремонт) и поле ввода своей категории; в «Ещё ›» и внутри подкатегорий сортировка по частоте использования; «Партии (FIFO)» внутри счёта убраны под спойлер; из «Отчёта» убраны «Капитал по месяцам» и «Экспорт месяца»; из «Ещё» убран мастер настройки, а выбор основной валюты перенесён внутрь «Моих валют».
- **Сворачивание подкатегорий в «Отчёте» (4.5):** по умолчанию все подкатегории свёрнуты, строка категории компактна; у категорий с подкатегориями стрелочка ▸, нажатие раскрывает подкатегории (▾) и сворачивает обратно. Галочки фильтрации на квадратике слева сохранены.
- **Фото чека (4.6, 2026-11-14):** владелец передумал и согласовал. Фото чека (камера или галерея) → Google Gemini → позиции на русском, разложенные по категориям; экран проверки, «Исправить», выбор счёта; один чек = несколько расходов с общим полем `rid`. Ключ Gemini вводит владелец (хранится отдельно от данных). Голосовой ввод остаётся отвергнутым.
- **Операции из уведомлений BIDV (4.7, 2026-11-14):** служба `BankNotifListener` ловит только уведомления с «Transaction amount» и «Ending balance»; на главной появляется карточка, баланс не меняется до подтверждения. Расход: «Вручную» или «По чеку» (один экран разноса, счётчик «Осталось распределить», галочка при равенстве), поступление: «Обмен» (одна строка «откуда + сумма»), «Доход» или «Перевод». Получателя запоминаем по номеру из текста, предлагаем самую частую категорию, счётчик «5 из 5» не показываем (по просьбе). Кнопка «Чек по фото» убрана с главной (остаётся в форме расхода). Т-Банк (SMS «Пополнение / Перевод», разрешение на чтение SMS) — отдельный второй этап, ещё не сделан. Сверка остатка по «Ending balance» пока не сделана.
- **4.8 (2026-11-14):** SMS Т-Банка («Пополнение / Перевод / Покупка…», `SmsReceiver`, разрешение RECEIVE_SMS) идут в ту же очередь, что уведомления BIDV; исходящий «Перевод» Т-Банка можно записать как обмен. «Ещё» упрощён: «Курсы валют» убраны в «Мои валюты», тема, все копии (резервная, GitHub, автокопия) и блок «Чек по фото и банк» свёрнуты в спойлеры, виджет убран из настроек (код виджета остался).
- **Отложено из этой серии:** SQLite заменён копией данных внутри приложения (меньше риска для данных).

## Отвергнуто — не предлагать заново
- Кольца лимитов на главном экране.
- Тост «отложить после зарплаты».
- Переносы строк в пункте 12 первого аудита (пропущено по просьбе).
- Размытие суммы на главном (убрано по просьбе).
- Голосовой ввод, ачивки, «финансовое зеркало», синхронизация между устройствами, пуши — нужны сервер или слишком тяжело.

## Отложено (только по явному «да»)
- Свои подкатегории для любой категории (пользователь отложил).
- PIN или биометрия на вход.
- APK через Capacitor + GitHub Actions (уведомления, отпечаток, автобэкап, виджет) — приоритеты не выбраны.
- «Копилки» как отдельные счета со своими целями.
- Постраничный список операций (200 + «показать ещё»): на ~4000 строк рендер ≈0,9 с.
- Ввод операций текстом через AI-ключ.
