# Решения владельца, отложенное и «не делать»

Сверяйся с этим файлом, прежде чем предлагать идеи. Обновляй его, когда появляется новое решение.

## Принято и сделано
- **Курсы:** убрали «свой / официальный курс». Порядок: FIFO-средний по лежащим партиям → ручной → рыночный → ЦБ.
- **Прогнозы** показываются только после 30 дней данных. Счета можно отключать от прогноза (например, карту РФ).
- **Категория «Еда» → «Продукты»** (еда вне дома остаётся отдельной).
- **Лимиты:** кольца убрали; в «Отчёте» и «Лимитах» — полосы и кольцевая диаграмма.
- **Накопления:** калькулятор «Как дойти до цели»; копилка в нескольких валютах, видны рублёвый эквивалент и рыночная стоимость.
- **Мопед** (2.22): подкатегории Топливо / Обслуживание / Покупка. «Покупка» — разовая, не входит в среднюю трату в день.
- **Мама** (2.27): категория для переводов маме; в среднюю трату в день и прогноз не входит.
- **Цитата дня** на главной (2.24), можно выключить.
- **Иконка** (2.23): четырёхлистный клевер в золотой подкове.
- **Имя файла копии** (2.25): `LuckyFinance_backup_ГГГГ-ММ-ДД_ЧЧ-ММ.json`.
- **Цветные темы** (2.26): Изумруд, Закат, Океан, Неон, Лаванда рядом с «Классикой».
- **Копия на GitHub** (2.28): в приватный репозиторий пользователя, токен в отдельном ключе `fin-mvp-gh`, автовыгрузка раз в день при открытии, если данные менялись.
- **Финпомощник:** приложение само AI не вызывает; сводка выгружается и задаётся вопрос на отдельной странице-артефакте claude.ai за счёт подписки пользователя.
- **Подкатегории** (2.29, 2.30): необязательные, на механизме `SUBS`. Продукты (фрукты и овощи, мясо/рыба/яйца, молочка/хлеб/бакалея, кулинария, прочее), Еда вне дома (кафе, стритфуд, доставка), Кофе и напитки (кофе, напитки), Здоровье (аптека, врачи, страховка), Жильё (коммуналка, прачечная), Спорт (тренажёрный зал, спортивное питание). Алкоголь и бары пользователь убрал. Свои подкатегории по-прежнему отложены.
- **Отчёт** (2.31): прогноз до 30 дней данных — компактная плашка; «Пульс месяца» выше, разовые траты золотой меткой; в категориях топ-5 и «Ещё N категорий»; подкатегории полосками; графики по месяцам только с месяцев с данными.
- **«Разовая трата»** (2.32): переключатель в форме расхода (поле `oneoff`, хранится только если отличается от умолчания). Все расходы остаются в итогах, категориях и остатках; разовые не входят только в среднюю трату в день и прогнозы. По умолчанию разовые: «Мопед · Покупка» и «Мама». «Среднее в день» в «Итогах месяца» считается без разовых.
- **Главный экран:** без отдельных «колец лимитов» и без уведомления «отложи после зарплаты» — пользователь отверг. Под выбором валют подсказки спрятаны под спойлер.

- **Версия 3.0 — формат APK (Capacitor)**: убраны установка на «Домой», iOS-код, service worker, баннер обновления; шрифты лежат в `fonts/` (кириллица, латиница, вьетнамский). Кнопка «Назад», вибро, чёрная AMOLED-тема, уведомления о платежах и лимитах, виджет, ярлыки (`luckyfinance://op/<тип>`), автокопия файлом в «Документы/LuckyFinance», страховочная копия данных внутри приложения, экспорт месяца CSV и PDF. «Что нового» — последние 5 версий.
- **Темы (3.0):** остались «Классика», «Эспрессо» (кофейная, тёмная) и «AMOLED»; Изумруд, Закат, Океан, Неон, Лаванда убраны.
- **Обновление из GitHub (3.1):** кнопка в «Ещё», приложение скачивает файлы из GitHub Pages в память телефона и переключается на них без переустановки APK; проверено на эмуляторе (успешное обновление и откат сломанной версии). Новый APK нужен только при смене нативной части.
- **Фото чека (C7):** отвергнуто, не предлагать.
- **Отложено из этой серии:** SQLite заменён копией данных внутри приложения (меньше риска для данных).

## Отвергнуто — не предлагать заново
- Кольца лимитов на главном экране.
- Тост «отложить после зарплаты».
- Переносы строк в пункте 12 первого аудита (пропущено по просьбе).
- Размытие суммы на главном (убрано по просьбе).
- Голосовой ввод, ачивки, «финансовое зеркало», синхронизация между устройствами, пуши — нужны сервер или слишком тяжело.

## Отложено (только по явному «да»)
- Свои подкатегории для любой категории (пользователь отложил).
- PIN или биометрия на вход.
- APK через Capacitor + GitHub Actions (уведомления, отпечаток, автобэкап, виджет) — приоритеты не выбраны.
- «Копилки» как отдельные счета со своими целями.
- Постраничный список операций (200 + «показать ещё»): на ~4000 строк рендер ≈0,9 с.
- Ввод операций текстом через AI-ключ.
- Фото чека к операции.
