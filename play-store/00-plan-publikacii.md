# Публикация Lucky Finance в Google Play: пошаговый план

## 0. Что нужно знать заранее
- **Аккаунт разработчика Google Play: разовый платёж $25.** Бесплатного варианта нет. Нужны банковская карта (подойдёт карта, принимающая платежи в USD за рубежом) и документ, удостоверяющий личность.
- **Личный аккаунт, созданный после 13.11.2023:** перед выпуском в продакшен нужно **закрытое тестирование: минимум 12 тестировщиков, 14 дней подряд**. Это требование Google. Тестировщики добавляются по email (Gmail-аккаунтам).
- Проверка нового аккаунта и первого приложения занимает от нескольких дней до пары недель.
- Если Play не подходит: APK можно раздавать напрямую или через GitHub Releases, без аккаунта.

## 1. Аккаунт
1. https://play.google.com/console/signup
2. Тип аккаунта: **Личный**. Заполнить имя, адрес, телефон, оплатить $25.
3. Подтвердить личность (документ) и устройство Android через приложение Play Console.
4. Дождаться одобрения.

## 3. Политика конфиденциальности
Play требует ссылку на страницу, доступную без входа. Самый простой способ: положить `privacy-policy.html` в корень репозитория `lucky_finance` (он уже на GitHub Pages). Ссылка будет:
`https://godoffear.github.io/lucky_finance/privacy-policy.html`
Перед публикацией впишите в файл свой email (место помечено `[ВАШ EMAIL]`).

## 4. Подпись и сборка AAB (это я сделаю по вашей команде)
Play принимает **AAB**, а не APK, и приложение должно быть подписано **вашим постоянным ключом**.
1. Создаётся keystore (файл ключа) и пароль. **Файл и пароль нужно сохранить в нескольких местах.** Потеряете ключ: не сможете обновлять приложение.
2. Рекомендую включить Play App Signing (Google хранит основной ключ, у вас ключ загрузки): это страховка от потери.
3. Увеличиваем `versionCode` при каждой новой загрузке (сейчас 1).
4. Собирается файл `app-release.aab`.
Целевой уровень API у проекта 36, это соответствует требованиям Google на 2026 год.

## 5. Создание приложения в Play Console
1. **Создать приложение**: название Lucky Finance, язык по умолчанию русский, «Приложение», «Бесплатное».
2. **Панель → Настройка приложения** — заполнить по порядку:
   - Политика конфиденциальности (ссылка из шага 3)
   - Доступ к приложению: «Весь функционал доступен без ограничений»
   - Реклама: **нет**
   - Возрастной рейтинг: опросник, ответы в `01-listing.md`
   - Целевая аудитория: **18+** (не для детей)
   - Безопасность данных: по `02-data-safety.md`
   - Финансовые функции: выбрать «Приложение не является финансовым сервисом» (учёт без платежей, кредитов и инвестиций)
   - Категория: **Финансы**, контакты: email, сайт необязателен
3. **Основная страница в Google Play**: тексты и графика из `01-listing.md`.

## 6. Тестирование и выпуск
1. Тестирование → **Закрытое тестирование** → создать трек, загрузить AAB.
2. Добавить список из 12+ email тестировщиков, разослать им ссылку-приглашение.
3. Через **14 дней** подать заявку на продакшен («Запросить доступ к продакшену»).
4. После одобрения: Продакшен → создать релиз → отправить на проверку (1–7 дней).

## 7. Обновления после выпуска
Правки в приложении → `npm run sync` → поднять `versionCode`/`versionName` → собрать AAB → загрузить новый релиз.
