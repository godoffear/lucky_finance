# Форма «Безопасность данных» (Data safety)

Основа: у приложения нет сервера и аккаунтов. Данные хранятся только на устройстве. Единственные сетевые запросы: курсы валют и (по желанию пользователя) выгрузка бэкапа в его собственный репозиторий GitHub.

## Ответы на вопросы
| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт ли пользовательские данные? | **Нет** с точки зрения разработчика: данные не покидают устройство и не попадают к разработчику |
| Шифруются ли данные при передаче? | **Да** (все запросы по HTTPS) |
| Можно ли запросить удаление данных? | **Да**: данные хранятся на устройстве, удаляются в приложении («Сброс») или удалением приложения |
| Следует ли приложение политике Families | Нет (не для детей) |
| Реклама | Нет |
| Независимая проверка безопасности | Нет |

## Типы данных
Отметьте **«Данные не собираются»** для всех категорий (финансовая информация, личная информация, местоположение, фото, контакты и др.).

### Обоснование (на случай вопроса от проверяющего)
- Финансовые записи пользователя остаются в локальном хранилище приложения и разработчику недоступны.
- Запросы курсов (`cbr-xml-daily.ru`, `currency-api.pages.dev`) не содержат персональных данных пользователя.
- Выгрузка копии в GitHub идёт напрямую с устройства в репозиторий самого пользователя по его токену. Токен хранится только на устройстве. Разработчик эти данные не получает. Функция включается пользователем вручную.

## Разрешения
Только `INTERNET`. Камера, микрофон, геолокация, контакты, SMS, хранилище не запрашиваются.
