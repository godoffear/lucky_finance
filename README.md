# Lucky Finance 🍀

**Получаешь в одной валюте, тратишь в другой? Ты по адресу.**

Обычные трекеры пересчитывают всё по курсу из интернета, а деньги обменяны по другому курсу — вот цифры и не сходятся. Lucky Finance помнит, по какому курсу обменена каждая сумма, и показывает, во сколько на самом деле обошёлся кофе, аренда или билет.

- 💱 Остаток в любой валюте: рубли, донги, доллары, крипта
- ⏳ Сколько хватит денег и сколько менять — без гаданий
- 🔁 Напоминает про аренду и подписки, а платёж вносится только по твоему нажатию
- 🍀 Без регистрации и бесплатно, данные остаются на твоём устройстве

Ничего не списывается и не откладывается само: все решения за тобой.

## Как установить

- **Android (Chrome):** меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## О данных

Все данные хранятся только в браузере на твоём устройстве, на сервер ничего не отправляется. Делай резервную копию: «Ещё → Резервная копия».
